CAREER XI - free PWA prototype

Run locally:
1. Open a terminal in this folder.
2. Run: python -m http.server 8000
3. Open http://localhost:8000

The career save is stored in your browser using localStorage.

Included:
- Player creation
- Career start and club selection
- Career hub
- Player attributes/training
- Match simulation
- Medium-control match decisions
- League table
- Manager trust, fitness and form
- Career match history
- Offline-capable PWA shell
